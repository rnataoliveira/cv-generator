# Release v0.1.0 — Initial release

Release date: 2026-02-15

Highlights

- Initial public release of CV Generator.
- Features:
  - Live editor and preview for CV data (name, contact, summary, skills, experience, education, photo).
  - Two printable templates (Template A and Template B).
  - Locale support: English (`en`) and Portuguese (pt-BR).
  - Client-side PDF export using `html2pdf.js` with A4-sized output.
  - Unit tests with Vitest and basic CI checks.
  - GitHub Actions workflows for Pages deployment and release creation.

How to use

1. Run locally:

```bash
npm ci
npm run dev
```

2. Create PDFs from the editor using the Download buttons (EN / PT-BR).

Notes

- The app is designed to be stateless (no backend) — image uploads are stored as data-URLs in the browser.
- For GitHub Pages, the repository uses `main/docs` publishing (CI copies `dist/` to `docs/`).

Changelog (short)

- Added editor, preview, templates, export, i18n, tests, CI.

Acknowledgements

- Built with React, Vite, Tailwind, html2pdf.js, Vitest.
